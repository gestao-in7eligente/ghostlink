> **Beta.** Ghost DJ, o bot de música de todo servidor, e o menu do canal. *Ghost DJ, every server's music bot, and the channel menu.* — [English below](#english)

## Português

### O que mudou

- **Ghost DJ:** todo servidor ganha um bot de música. Num canal de voz, use **/play** com o nome ou o link do YouTube (playlists também), e ainda **/pause**, **/resume**, **/skip**, **/stop**, **/queue**, **/nowplaying**, **/volume** e **/loop**. Um painel **Tocando agora** fica no chat. Quem manda é quem está no canal de voz com o DJ, e ele sai sozinho depois de 5 min parado.
- **Menu do canal (clique direito num canal de texto):** Marcar como lida, Convite para o canal (quem entra cai direto nele), Fixe o Canal no Topo, Copiar link, **Silenciar canal ›**, **Config. de notificação ›** por canal, Editar, Duplicar, Criar e Excluir canal, e Copiar ID do canal.
- **Links de canal no chat:** um link `ghostlink://channel/…` vira um **#canal** clicável.

### Atualizar

O app se atualiza sozinho ao abrir. **Os servidores também mudam nesta versão** e se atualizam sozinhos quando ninguém está em chamada:
- **Railway e Docker:** nada a fazer, a imagem nova já traz tudo.
- **VPS:** o Ghost DJ precisa do `ffmpeg`. Rode o `install.sh` desta versão de novo ou `sudo apt install ffmpeg` e reinicie o servidor.
- **YouTube bloqueando o servidor** ("Sign in to confirm you're not a bot", comum em nuvem): coloque um arquivo de cookies do YouTube em `ghost-dj/cookies.txt` na pasta de dados do servidor. O guia de hospedagem explica.
- Servidores hospedados pelo próprio app no Windows ainda não têm o Ghost DJ.

### Instalar no Windows

Baixe `GhostLink-Setup-0.5.0.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.5.0.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

1. **Checksums com Sigstore (cosign):**

   ```bash
     --certificate-oidc-issuer https://token.actions.githubusercontent.com

   ```

## English

### What changed

- **Ghost DJ:** every server gets a music bot. In a voice channel, use **/play** with a YouTube name or link (playlists too), plus **/pause**, **/resume**, **/skip**, **/stop**, **/queue**, **/nowplaying**, **/volume** and **/loop**. A **Now playing** panel stays in the chat. Whoever is in the voice channel with the DJ controls it, and it leaves by itself after 5 idle minutes.
- **Channel menu (right-click a text channel):** Mark as read, Invite to channel (whoever joins lands in it), Pin channel to top, Copy link, **Mute channel ›**, per-channel **Notification settings ›**, Edit, Duplicate, Create and Delete channel, and Copy channel ID.
- **Channel links in the chat:** a `ghostlink://channel/…` link becomes a clickable **#channel**.

### Updating

The app updates itself when it opens. **Servers change in this version too** and update themselves when nobody is in a call:
- **Railway and Docker:** nothing to do, the new image has everything.
- **VPS:** the Ghost DJ needs `ffmpeg`. Run this version's `install.sh` again or `sudo apt install ffmpeg`, then restart the server.
- **YouTube blocking the server** ("Sign in to confirm you're not a bot", common in the cloud): put a YouTube cookies file at `ghost-dj/cookies.txt` in the server's data folder. The hosting guide explains it.
- Servers hosted by the app itself on Windows don't have the Ghost DJ yet.

### Install on Windows

Download `GhostLink-Setup-0.5.0.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.5.0.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
