> **Beta.** Quem tem uma chave cria o servidor na nuvem certo de forma confiável, sem depender de uma reverificação ao abrir o app. *With a key, you create the right cloud server reliably, without depending on a re-check at startup.* — [English below](#english)

## Português

### O que mudou

- **Criar servidor na nuvem respeita a chave de forma confiável:** antes, se o serviço de licenças engasgava quando o app abria, uma instalação com a chave podia acabar criando o servidor comum sem querer. Agora a chave guardada no app já basta — a validade segue conferida quando o servidor ativa a chave.
- Correções e melhorias internas de estabilidade.

### Atualizar

O app se atualiza sozinho ao abrir. Os servidores que você criou acompanham a versão quando ninguém está em chamada.

### Instalar no Windows

Baixe `GhostLink-Setup-0.8.9.exe` abaixo. O Windows SmartScreen avisa na primeira vez: **Mais informações → Executar assim mesmo**. Instala só para o seu usuário, sem administrador.

### Verificar o download

Assinado com a chave Ed25519 que o app confere antes de atualizar. Salve a chave pública como `ghostlink-release.pem`:

```text
-----BEGIN PUBLIC KEY-----
MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
-----END PUBLIC KEY-----
```

```bash
openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
  -in GhostLink-Setup-0.8.9.exe -sigfile GhostLink-Setup-0.8.9.exe.ed25519
```

## English

### What changed

- **Cloud server creation respects the key reliably:** before, if the license service hiccuped as the app opened, an install that holds the key could end up creating a plain server by mistake. Now the key stored in the app is enough — its validity is still checked when the server activates it.
- Internal stability fixes and improvements.

### Updating

The app updates itself when it opens. The servers you created follow the version when nobody is in a call.

### Install on Windows

Download `GhostLink-Setup-0.8.9.exe` below. Windows SmartScreen warns the first time: **More info → Run anyway**. Installs for your user only, no administrator.

### Verify the download

```text
-----END PUBLIC KEY-----
```

```bash
openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
  -in GhostLink-Setup-0.8.9.exe -sigfile GhostLink-Setup-0.8.9.exe.ed25519
```
