> **Beta.** Ative sua licença no próprio app e crie servidores na nuvem até o limite da sua chave. *Activate your license in the app and create cloud servers up to your key's limit.* — [English below](#english)

## Português

### O que mudou

- **Nova aba "Licença"** nas configurações, abaixo do Perfil: quem tem uma chave de registro pode ativá-la no próprio GhostLink. Com a chave ativa, você cria servidores na nuvem (Railway) até o limite da chave, e o app passa a se atualizar sozinho.
- Correções e melhorias internas de estabilidade.

### Atualizar

O app se atualiza sozinho ao abrir. Os servidores que você criou acompanham a versão quando ninguém está em chamada.

### Instalar no Windows

Baixe `GhostLink-Setup-0.8.8.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: **Mais informações → Executar assim mesmo**. Instala só para o seu usuário, sem administrador.

### Servidor numa VPS

`ghostlink-server-0.8.8.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar o download

Assinado com a chave Ed25519 que o app confere antes de atualizar. Salve a chave pública como `ghostlink-release.pem`:

```text
-----BEGIN PUBLIC KEY-----
MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
-----END PUBLIC KEY-----
```

```bash
openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
  -in GhostLink-Setup-0.8.8.exe -sigfile GhostLink-Setup-0.8.8.exe.ed25519
```

## English

### What changed

- **New "License" tab** in settings, below Profile: anyone with a registration key can activate it right in GhostLink. With the key active, you can create cloud (Railway) servers up to the key's limit, and the app keeps itself updated.
- Internal stability fixes and improvements.

### Updating

The app updates itself when it opens. The servers you created follow the version when nobody is in a call.

### Install on Windows

Download `GhostLink-Setup-0.8.8.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: **More info → Run anyway**. It installs for your user only, no administrator.

### Server on a VPS

`ghostlink-server-0.8.8.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
