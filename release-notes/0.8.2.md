## Português

### O que mudou

- Correções e melhorias internas de segurança e de estabilidade.

### Atualizar

O app se atualiza sozinho ao abrir. **Os servidores também mudam nesta versão** e se atualizam sozinhos quando ninguém está em chamada.

### Instalar no Windows

Baixe `GhostLink-Setup-0.8.2.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.8.2.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.8.2" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.8.2.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.8.2.exe -sigfile GhostLink-Setup-0.8.2.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.8.2 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.8.2" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   ```

Mais detalhes: https://gestao-in7eligente.github.io/ghostlink/verificar-downloads

## English

### What changed

- Internal security and stability fixes and improvements.

### Updating

The app updates itself when it opens. **Servers change in this version too** and update themselves when nobody is in a call.

### Install on Windows

Download `GhostLink-Setup-0.8.2.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

`ghostlink-server-0.8.2.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
