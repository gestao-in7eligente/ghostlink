> **Beta.** Primeira versão pública do GhostLink. *First public GhostLink release.* — [English below](#english)

## Português

GhostLink é um app gratuito e de código aberto de chat de texto e voz, no estilo do Discord, em que **qualquer pessoa hospeda o próprio servidor**, pelo app ou numa VPS. Não existe conta: sua identidade é uma chave que fica no seu computador.

### O que tem nesta versão

- **Texto:** canais, histórico, respostas, edição e exclusão, reações, menções e não lidas, markdown seguro, quem está online e digitando, notificações de menções e respostas.
- **Cargos e moderação:** cargos com hierarquia, permissões aplicadas pelo servidor, canais privados, convites com limite de usos e validade, expulsar, banir, sair do servidor, transferir e recuperar a posse, configurações do servidor.
- **Voz** (LiveKit): entrar e sair, mutar e ensurdecer, indicador de quem fala, escolha de dispositivos, volume por pessoa, silenciar e mover pelo servidor, push-to-talk no app e global no Windows.
- **Hospedar:** botão **Hospedar** no app, com UPnP, detecção de endereços e de CGNAT, aviso de porta ocupada, correção do firewall do Windows e bandeja; servidor para VPS Linux com `install.sh`.
- **Identidade:** backup e importação (`.ghostkey`) e links de convite `ghostlink://`.
- **Atualização automática** no Windows, verificada com a assinatura Ed25519 da release.
- Português e inglês.

**Ainda não tem:** câmera, compartilhamento de tela, arquivos e imagens, avatares e a versão para macOS. Eles vêm nas próximas versões.

### Instalar no Windows

Baixe `GhostLink-Setup-0.1.0.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador. Confira o download antes (abaixo) se quiser ter certeza de que ele veio desta release.

### Servidor numa VPS

`ghostlink-server-0.1.0.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. O guia está no site: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.1.0" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.1.0.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.1.0.exe -sigfile GhostLink-Setup-0.1.0.exe.ed25519
   ```

## English

GhostLink is a free and open-source Discord-style text and voice chat app where **anyone can host their own server**, from the app or on a VPS. There is no account: your identity is a key that stays on your computer.

### In this version

- **Text:** channels, history, replies, edit and delete, reactions, mentions and unread counts, safe markdown, online and typing indicators, notifications for mentions and replies.
- **Roles and moderation:** roles with a hierarchy, permissions enforced by the server, private channels, invites with use limits and expiry, kick, ban, leave, ownership transfer and recovery, server settings.
- **Voice** (LiveKit): join and leave, mute and deafen, speaking indicator, device choice, per-person volume, server mute and move, push-to-talk in the app and globally on Windows.
- **Hosting:** a **Host** button in the app, with UPnP, address and CGNAT detection, busy-port warnings, a Windows firewall fix and a tray icon; a Linux VPS server with `install.sh`.
- **Identity:** backup and import (`.ghostkey`) and `ghostlink://` invite links.
- **Automatic updates** on Windows, verified with the release's Ed25519 signature.
- Portuguese and English.

**Not yet:** camera, screen sharing, files and images, avatars and the macOS app. They come in the next versions.

### Install on Windows

Download `GhostLink-Setup-0.1.0.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights. Verify the download first (below) if you want to be sure it came from this release.

### Server on a VPS

`ghostlink-server-0.1.0.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
