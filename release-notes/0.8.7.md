> **Beta.** Dá para trocar um token do Railway que parou de funcionar, sem travar na tela de erro. *You can replace a Railway token that stopped working, without getting stuck on the error screen.* — [English below](#english)

## Português

### O que mudou

- **Trocar um token do Railway recusado:** antes, se o token salvo deixava de funcionar, a janela de criar servidor mostrava só o erro — sem como corrigir. Agora ela volta ao formulário de conexão, com o aviso, para você colar outro token (ou testar e conectar de novo).
- Correções e melhorias internas de estabilidade.

### Atualizar

O app se atualiza sozinho ao abrir. Nesta versão o servidor não muda de comportamento, só acompanha o número da versão quando ninguém está em chamada.

### Instalar no Windows

Baixe `GhostLink-Setup-0.8.7.exe` abaixo. O Windows SmartScreen avisa na primeira vez: **Mais informações → Executar assim mesmo**. Instala só para o seu usuário, sem administrador.

## English

### What changed

- **Replace a refused Railway token:** before, if the saved token stopped working, the create-server dialog showed only the error — with no way to fix it. Now it returns to the connection form, with the notice, so you can paste another token (or test and connect again).
- Internal stability fixes and improvements.

### Updating

The app updates itself when it opens. In this version the server does not change behavior, it only follows the version number when nobody is in a call.

### Install on Windows

Download `GhostLink-Setup-0.8.7.exe` below. Windows SmartScreen warns the first time: **More info → Run anyway**. Installs for your user only, no administrator.
