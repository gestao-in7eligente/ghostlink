## Português

### O que mudou

- **A aba Enterprise mostra a licença ativa:** num servidor Enterprise, **Configurações do servidor → Enterprise** agora mostra um cartão da licença no lugar do formulário: "Enterprise ativo", a empresa, "válida até" e os dias que faltam. Nos 7 dias antes de vencer o cartão fica de aviso ("Vence em N dias"); nos 7 dias depois, de perigo, com os dias até o servidor voltar a ser normal. **Renovar ou trocar licença** abre logo abaixo a identidade do servidor e o campo para colar; o formulário fecha ao salvar e continua aberto, com o erro, se a licença for recusada. Um servidor normal fica como antes.

Só o app muda nesta versão; os servidores não precisam de atualização.

### Atualizar

O app se atualiza sozinho ao abrir. Os servidores não mudam nesta versão.

### Instalar no Windows

Baixe `GhostLink-Setup-0.6.1.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.6.1.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.6.1" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.6.1.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.6.1.exe -sigfile GhostLink-Setup-0.6.1.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.6.1 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.6.1" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   ```

## English

### What changed

- **The Enterprise tab shows the active license:** on an Enterprise server, **Server settings → Enterprise** now shows a license card instead of the form: "Enterprise active", the company, the valid-until date and the days left. In the 7 days before expiry the card turns amber ("Expires in N days"); in the 7 days after, red, with the days left before the server goes back to normal. **Renew or replace license** opens the server identity and the paste form below; it closes after saving, and stays open with the error if the license is refused. A normal server looks as before.

Only the app changes in this version; servers need no update.

### Updating

The app updates itself when it opens. Servers do not change in this version.

### Install on Windows

Download `GhostLink-Setup-0.6.1.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.6.1.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
