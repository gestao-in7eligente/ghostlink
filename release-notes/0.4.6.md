> **Beta.** Transmissões ao vivo direto no quadrado da call. *Screen shares play live in their tile.* — [English below](#english)

## Português

### O que mudou

- **Transmissão no quadrado, sem clicar em Assistir:** quando alguém compartilha a tela na call, a transmissão aparece ao vivo no quadrado dela, ao lado das pessoas, inclusive as que já estavam no ar quando você entrou. Clique no quadrado para ver grande; **Voltar para a grade** (no canto de cima) volta. **Parar de assistir** continua existindo para economizar internet, e aí o quadrado mostra **Assistir** até você clicar de novo (só naquela transmissão).

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Nada muda nos servidores nesta versão.

### Instalar no Windows

Baixe `GhostLink-Setup-0.4.6.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.4.6.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.4.6" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.4.6.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.4.6.exe -sigfile GhostLink-Setup-0.4.6.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.4.6 \
   ```

## English

### What changed

- **Screen shares in their tile, no Watch click:** when someone shares their screen in the call, it plays live in its own tile next to the people, including shares already live when you join. Click the tile to see it large; **Back to the grid** (top corner) returns. **Stop watching** is still there to save bandwidth; the tile then shows **Watch** until you click it again (for that share only).

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Nothing changes on servers in this version.

### Install on Windows

Download `GhostLink-Setup-0.4.6.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.4.6.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
