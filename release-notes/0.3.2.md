## Português

### O que mudou

- **Ícone do servidor:** em **Configurações do servidor → Visão geral → Ícone do servidor**, quem gerencia o servidor escolhe uma imagem (com zoom e arrastar, GIF animado também). O ícone aparece no trilho, no cabeçalho do servidor e no "Ativo agora"; sem ícone, ficam as iniciais. Precisa do servidor na 0.3.2 (ele se atualiza sozinho).
- **Fechar vai para a bandeja (como o Discord):** o **X** esconde a janela e o GhostLink continua rodando — chamadas, mensagens e notificações seguem. O fantasma fica perto do relógio: um clique abre a janela; o clique direito tem **Abrir GhostLink** e **Sair do GhostLink**. Para fechar de verdade ao clicar no X, desligue **Ao fechar, manter na bandeja** em **Configurações → Janela**.

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Amigos e mensagens diretas funcionam entre apps na 0.3.2. Os servidores vão para a 0.3.2 sozinhos quando ninguém estiver em chamada, mas nada muda neles: amigos e mensagens diretas não passam por servidor.

### Instalar no Windows

Baixe `GhostLink-Setup-0.3.2.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.3.2.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.3.2" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.3.2.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.3.2.exe -sigfile GhostLink-Setup-0.3.2.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.3.2 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.3.2" \
   ```

## English

### What changed

- **Server icon:** in **Server settings → Overview → Server icon**, people who manage the server pick an image (zoom and drag, animated GIFs too). It shows in the rail, the server header and "Active Now"; without one, initials show. Needs a 0.3.2 server (it updates by itself).
- **Closing goes to the tray (like Discord):** the **X** hides the window and GhostLink keeps running — calls, messages and notifications go on. The ghost sits near the clock: a click opens the window; right-click has **Open GhostLink** and **Quit GhostLink**. To really quit on X, turn **Keep in the tray when closed** off in **Settings → Window**.

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Friends and direct messages work between apps on 0.3.2. Servers move to 0.3.2 by themselves when no one is in a call, but nothing changes on them: friends and direct messages never go through a server.

### Install on Windows

Download `GhostLink-Setup-0.3.2.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.3.2.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
