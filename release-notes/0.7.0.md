> **Beta.** A aba API e a categoria Sites no Hermes da empresa. *The API tab and the Sites category for the company Hermes.* — [English below](#english)

## Português

### O que mudou

- **Aba API:** a página do Hermes da empresa ganha a aba **API**, logo depois de **Memória**, só do dono. Ela guarda todas as chaves que o Hermes usa e substitui **Chaves de IA** das configurações; as chaves da DeepSeek e da OpenRouter que já existiam continuam valendo e aparecem nela.
  - **Catálogo:** as IAs DeepSeek, OpenRouter, OpenAI, Anthropic e Google Gemini, e também ElevenLabs, Grok (xAI) e Yunwu.
  - **Outra API:** um nome e a variável onde a chave fica, em maiúsculas e terminada em `_KEY`, `_TOKEN`, `_SECRET` ou `_PASSWORD`. Nomes do sistema, do Hermes e do GhostLink são recusados. Até 30 chaves no total.
  - **As chaves ficam só no servidor e na memória do Hermes.** Depois de salva, uma chave só aparece pelos 4 últimos caracteres; ela nunca volta para o app, nunca vai para os logs e nunca é gravada em arquivo no Hermes.
  - As chaves de IA são testadas sem gastar tokens ("teste: ok" ou "teste: recusada"), e as IAs com chave aparecem como provedores em **Modelos**.
- **Categoria Sites:** num servidor Enterprise, **SITES** aparece logo abaixo de **BOTS**.
  - **Quem cadastra:** o dono e o cargo que vê a página do Hermes, pelo **+** da categoria. Cada site tem nome, endereço (só o domínio, ex. `es.profetacristao.com`) e canal de texto.
  - **O canal:** um que já existe, que vai para Sites com todo o histórico, ou **Criar canal novo**, com o nome do endereço. Os canais que já têm nome de site entram de uma vez com **Cadastrar como sites**.
  - **Editar site** e **Remover site** ficam no botão direito do site. Removido, o site devolve o canal para "Canais de texto", sem apagar nada. Quem não vê o canal não vê o site. Até 50 sites.
  - **O que o Hermes posta** no canal de cada site: ✅ cada ação que fez no site, com o link; ⚠️ os erros e bloqueios; e, às 23h (horário de São Paulo), 📋 um resumo do dia, só nos sites que tiveram atividade.
- **Plugin GhostLink do Hermes 1.2:**
  - Põe cada chave da aba API numa variável do ambiente do processo e tira a que for apagada no GhostLink. Uma variável que já estava no ambiente quando o Hermes ligou (do Railway, por exemplo) nunca é trocada por uma "Outra API" nem apagada.
  - As chaves de IA e a da ElevenLabs o próprio Hermes esconde dos comandos de terminal; as outras os scripts das skills leem.
  - Para os sites, gera a skill `ghostlink-sites` (sem nenhum segredo), traz as ferramentas que postam no canal de cada site e mantém o agendamento do resumo das 23h no agendador do próprio Hermes.
  - Continua funcionando com servidores 0.6, e o plugin 1.1 continua funcionando com servidores 0.7 (só com DeepSeek e OpenRouter, sem as outras chaves e sem os sites).
  - **Atualize o plugin do Hermes para 1.2 antes de escolher OpenAI, Anthropic ou Gemini em Modelos.** O plugin 1.1 trocaria o modelo sem pôr a chave dele no Hermes.

### Atualizar

O app se atualiza sozinho ao abrir. **Os servidores também mudam nesta versão** e se atualizam sozinhos quando ninguém está em chamada.

**O plugin do Hermes não se atualiza sozinho.** O Hermes da empresa (o TC Hermes também) precisa do **plugin 1.2** para receber as chaves novas e os sites: copie a pasta `integrations/hermes-agent/ghostlink/` desta versão para `$HERMES_HOME/plugins/ghostlink/` e reinicie o gateway.

**A chave do MCP do Macrol Dashboard (`MACROL_MCP_KEY`) vai nas variáveis do Railway do TC Hermes**, não na aba API e nem no `.env`. O Hermes conecta os servidores MCP quando liga, antes de o GhostLink mandar as chaves, e não reconecta depois; por isso uma chave da aba API chegaria tarde para o MCP. No `.env`, ela ficaria gravada em arquivo.

## English

### What changed

- **The API tab:** the company Hermes's page gets an **API** tab, right after **Memory**, for the owner only. It keeps every key the Hermes uses and replaces **AI keys** in the settings; the DeepSeek and OpenRouter keys already saved keep working and show up there.
  - **Catalog:** the DeepSeek, OpenRouter, OpenAI, Anthropic and Google Gemini AIs, plus ElevenLabs, Grok (xAI) and Yunwu.
  - **Another API:** a name and the variable that holds the key, in capitals and ending in `_KEY`, `_TOKEN`, `_SECRET` or `_PASSWORD`. System, Hermes and GhostLink names are refused. Up to 30 keys in all.
  - **Keys stay only on the server and in the Hermes's memory.** Once saved, a key shows only as its last 4 characters; it never comes back to the app, never goes to the logs and is never written to a file on the Hermes.
  - The AI keys are tested without spending tokens ("test: ok" or "test: refused"), and the AIs with a key show up as providers in **Models**.
- **The Sites category:** on an Enterprise server, **SITES** shows right below **BOTS**.
  - **Who registers sites:** the owner and the role that sees the Hermes's page, with the category's **+**. Each site has a name, an address (the domain only, e.g. `es.profetacristao.com`) and a text channel.
  - **The channel:** an existing one, which moves to Sites with all its history, or **Create a new channel**, named after the address. Channels already named like a site come in at once with **Add them as sites**.
  - **Edit site** and **Remove site** are on the site's right-click menu. A removed site gives its channel back to "Text channels", deleting nothing. Whoever cannot see the channel cannot see the site. Up to 50 sites.
  - **What the Hermes posts** in each site's channel: ✅ every action it took on the site, with the link; ⚠️ errors and blocks; and, at 11 p.m. (São Paulo time), 📋 a summary of the day, only for the sites that had activity.
- **Hermes's GhostLink plugin 1.2:**
  - Puts each API tab key in a variable of the process's environment and removes the one deleted in GhostLink. A variable that was already in the environment when the Hermes started (a Railway one, for example) is never replaced or removed by an "Another API" key.
  - Hermes itself hides the AI keys and the ElevenLabs key from terminal commands; the skills' scripts read the others.
  - For the sites, it writes the `ghostlink-sites` skill (with no secret in it), adds the tools that post in each site's channel and keeps the 11 p.m. summary job in Hermes's own scheduler.
  - It still works with 0.6 servers, and plugin 1.1 still works with 0.7 servers (with DeepSeek and OpenRouter only, without the other keys and without the sites).
  - **Update Hermes's plugin to 1.2 before choosing OpenAI, Anthropic or Gemini in Models.** Plugin 1.1 would switch the model without giving Hermes its key.

### Updating

The app updates itself when it opens. **Servers change in this version too** and update themselves when nobody is in a call.

**Hermes's plugin does not update itself.** The company Hermes (the TC Hermes too) needs **plugin 1.2** to get the new keys and the sites: copy this version's `integrations/hermes-agent/ghostlink/` folder to `$HERMES_HOME/plugins/ghostlink/` and restart the gateway.

**The Macrol Dashboard MCP key (`MACROL_MCP_KEY`) goes in the TC Hermes's Railway variables**, not in the API tab and not in `.env`. Hermes connects its MCP servers when it starts, before GhostLink sends the keys, and does not reconnect them later, so a key from the API tab would arrive too late for the MCP. In `.env`, it would be written to a file.
