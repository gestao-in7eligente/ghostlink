> **Beta.** Sair do servidor e excluir servidor com 48 h para voltar atrás. *Leave a server, and delete one with 48 h to undo.* — [English below](#english)

## Português

### O que mudou

- **Sair do servidor:** no clique direito do servidor, no ⋮ da Home e no menu do nome do servidor, quem é membro tem **Sair do servidor** (com a opção de apagar as suas mensagens). Se o servidor não responder, dá para tirá-lo só da sua lista. "Remover da lista" saiu do app.
- **Excluir servidor (só o dono):** nos mesmos menus e em **Configurações do servidor → Visão geral**. Para confirmar, digite o nome do servidor. Ele **sai do ar na hora** para todos e **só é apagado de vez depois de 48 h** — mensagens, canais, cargos e arquivos. Até lá, a faixa vermelha mostra **Restaurar servidor**. No prazo, servidores criados pelo app no Railway têm o projeto apagado, e os hospedados no PC têm a pasta apagada.
- **Correção:** um servidor do Railway com o mesmo nome de um servidor antigo hospedado no PC aparecia como "Seu servidor · parado". Agora o app reconhece o servidor do PC pela chave, nunca pelo nome.

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Os servidores vão para a 0.2.4 sozinhos quando ninguém estiver em chamada; **Excluir servidor** aparece quando o servidor já estiver na 0.2.4.

### Instalar no Windows

Baixe `GhostLink-Setup-0.2.4.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.2.4.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

## English

### What changed

- **Leave server:** in the server's right-click menu, the Home ⋮ and the server name menu, members get **Leave server** (optionally deleting their messages). If the server doesn't answer, you can take it off your list only. "Remove from list" is gone.
- **Delete server (owner only):** in the same menus and in **Server settings → Overview**. Type the server's name to confirm. It **goes offline right away** for everyone and **is erased for good after 48 h** — messages, channels, roles and files. Until then, a red banner offers **Restore server**. At the deadline, Railway servers created by the app have their project deleted, and servers hosted on the PC have their folder deleted.
- **Fix:** a Railway server named like an old server hosted on the PC showed as "Your server · stopped". The app now recognizes the PC's server by its key, never by name.

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Servers move to 0.2.4 by themselves when no one is in a call; **Delete server** appears once the server runs 0.2.4.

### Install on Windows

Download `GhostLink-Setup-0.2.4.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.2.4.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
