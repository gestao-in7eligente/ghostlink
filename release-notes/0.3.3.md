> **Beta.** Imagens e arquivos nos canais e nas mensagens diretas. *Images and files in channels and direct messages.* — [English below](#english)

## Português

### O que mudou

- **Enviar imagens e documentos:** nos canais e nas mensagens diretas, pelo **+** da caixa de mensagem, arrastando os arquivos para a janela ou colando com **Ctrl+V**. Até 10 arquivos por mensagem.
- **Ver sem sair da conversa:** imagens aparecem na mensagem e abrem grandes com um clique; vídeos e áudios tocam ali mesmo; os outros arquivos viram um cartão com nome, tamanho e **Baixar**, que sempre pergunta onde salvar.
- **Limites:** 25 MB por arquivo, por padrão. O dono do servidor muda o tamanho máximo por arquivo e o espaço total para arquivos em **Configurações do servidor → Visão geral**, onde também vê quanto já foi usado.
- **Mensagens diretas:** os arquivos vão direto de um PC para o outro, sem passar por nenhum servidor.
- **Servidores:** arquivos nos canais precisam do servidor na 0.3.3 (ele se atualiza sozinho).

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Arquivos nas mensagens diretas funcionam entre apps na 0.3.3. Os servidores vão para a 0.3.3 sozinhos quando ninguém estiver em chamada; enviar arquivos nos canais funciona quando o servidor já estiver na 0.3.3.

### Instalar no Windows

Baixe `GhostLink-Setup-0.3.3.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.3.3.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

   ```bash
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.3.3.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:

## English

### What changed

- **Send images and documents:** in channels and direct messages, with the **+** in the message box, by dragging files onto the window or by pasting with **Ctrl+V**. Up to 10 files per message.
- **See them without leaving the chat:** images show in the message and open large with a click; videos and audio play right there; other files become a card with the name, the size and **Download**, which always asks where to save.
- **Limits:** 25 MB per file by default. The server owner changes the largest file and the total space for files in **Server settings → Overview**, which also shows how much is used.
- **Direct messages:** files go straight from one PC to the other, never through a server.
- **Servers:** files in channels need a 0.3.3 server (it updates by itself).

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Files in direct messages work between apps on 0.3.3. Servers move to 0.3.3 by themselves when no one is in a call; sending files in channels works once the server runs 0.3.3.

### Install on Windows

Download `GhostLink-Setup-0.3.3.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.3.3.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
