> **Beta.** Visual novo no estilo do Discord e servidor na nuvem (Railway) criado pelo app. *New Discord-style look and a cloud server (Railway) created from the app.* — [English below](#english)

## Português

### O que mudou

- **Visual novo:** as cores, a barra de título e a tela inicial agora seguem o Discord. A Home mostra seus servidores com busca e abas, e o que está **ativo agora** neste computador.
- **Criar um servidor pergunta onde:** **Neste computador** (como antes) ou **Na nuvem (Railway)**.
- **Servidor no Railway, criado pelo app:** você cola um token da sua conta Railway uma vez e o app cria tudo sozinho (projeto, serviço, disco dos dados e endereço público), acompanha a publicação e entra como dono. O servidor fica no ar 24 horas, sem depender do seu computador nem de abrir portas no roteador. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-no-railway
  - O token fica criptografado no seu computador e só é enviado ao Railway.
  - O custo vai para a sua conta Railway (o plano Hobby, de US$ 5 por mês, costuma bastar para um grupo pequeno).
  - No Railway a voz passa por TCP: funciona bem para conversar, mas pode engasgar em conexões ruins.
- **Virar dono de um servidor remoto:** ao entrar por endereço, marque **Sou o dono deste servidor** e use o código de configuração que o servidor mostra ao iniciar.
- **Servidor atrás de um proxy TCP:** o servidor agora funciona em plataformas que só oferecem uma porta TCP e nenhum UDP (modo proxy), com voz incluída. Há uma imagem Docker oficial: `ghcr.io/gestao-in7eligente/ghostlink-server:0.2.0`.
- O ícone do fantasma aparece na janela e na barra de tarefas.

**Ainda não tem:** amigos e mensagens diretas (em desenvolvimento para a próxima versão), câmera, compartilhamento de tela, arquivos e imagens, avatares e a versão para macOS.

### Atualizar

Quem tem a 0.1.0 instalada recebe esta versão sozinho (ao abrir o app, ou em até 6 horas) e só precisa clicar em **Reiniciar para atualizar**. Servidores 0.1.0 continuam funcionando com o app novo.

### Instalar no Windows

Baixe `GhostLink-Setup-0.2.0.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.2.0.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.2.0" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.2.0.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.2.0.exe -sigfile GhostLink-Setup-0.2.0.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.2.0 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.2.0" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   ```

## English

### What changed

- **New look:** the colors, the title bar and the home screen now follow Discord. Home lists your servers with search and tabs, and what is **active now** on this computer.
- **Creating a server asks where:** **On this computer** (as before) or **In the cloud (Railway)**.
- **A Railway server, created from the app:** paste a token from your Railway account once and the app creates everything (project, service, data disk and public address), follows the deployment and joins as the owner. The server stays online 24 hours, without your computer and without opening router ports. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-railway
  - The token is stored encrypted on your computer and only sent to Railway.
  - The cost goes to your Railway account (the Hobby plan, US$ 5 a month, is usually enough for a small group).
  - On Railway, voice goes over TCP: fine for talking, but it may stutter on poor connections.
- **Becoming the owner of a remote server:** when joining by address, tick **I own this server** and use the setup code the server prints when it starts.
- **Server behind a TCP proxy:** the server now runs on platforms that offer a single TCP port and no UDP (proxy mode), voice included. There is an official Docker image: `ghcr.io/gestao-in7eligente/ghostlink-server:0.2.0`.
- The ghost icon shows on the window and the taskbar.

**Not yet:** friends and direct messages (in development for the next version), camera, screen sharing, files and images, avatars and the macOS app.

### Updating

If you have 0.1.0 installed, this version arrives by itself (when the app opens, or within 6 hours): just click **Restart to update**. 0.1.0 servers keep working with the new app.

### Install on Windows

Download `GhostLink-Setup-0.2.0.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.
