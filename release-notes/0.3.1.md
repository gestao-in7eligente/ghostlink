> **Beta.** A chamada continua enquanto você navega. *Your call goes on while you browse.* — [English below](#english)

## Português

### O que mudou

- **A chamada não cai ao navegar:** numa chamada, ir para a **casinha** ou abrir **outro servidor** não tira você da chamada. O painel embaixo mostra **"Voz conectada — {canal} / {servidor}"** com microfone, fone e desligar, e o servidor da chamada ganha um alto-falante verde no trilho. Clicar no nome do canal volta para ele na hora.
- **Conversar em outro servidor durante a chamada:** dá para ler e escrever no chat de outro servidor e continuar falando na chamada do primeiro.
- **A chamada só termina** quando você clica em **desligar**, entra em outra chamada ou fecha o app.

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Amigos e mensagens diretas funcionam entre apps na 0.3.1. Os servidores vão para a 0.3.1 sozinhos quando ninguém estiver em chamada, mas nada muda neles: amigos e mensagens diretas não passam por servidor.

### Instalar no Windows

Baixe `GhostLink-Setup-0.3.1.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.3.1.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

## English

### What changed

- **Your call doesn't drop while you browse:** in a call, going **Home** or opening **another server** keeps you in it. The panel shows **"Voice Connected — {channel} / {server}"** with mic, headphones and hang-up, and the call's server gets a green speaker in the rail. Clicking the channel name takes you back at once.
- **Chat on another server during a call:** read and write on another server while you keep talking in the first one's call.
- **The call only ends** when you click **hang up**, join another call or close the app.

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Friends and direct messages work between apps on 0.3.1. Servers move to 0.3.1 by themselves when no one is in a call, but nothing changes on them: friends and direct messages never go through a server.

### Install on Windows

Download `GhostLink-Setup-0.3.1.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.
