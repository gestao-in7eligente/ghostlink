## Português

### O que mudou

- **Página mais larga:** a página de todo bot (Hermes, Ghost DJ e bots comuns) agora ocupa até 1100 px, centralizada, e continua cabendo em janela estreita.
- **Abas no Hermes da empresa:** logo abaixo do selo, **Visão geral**, **Skills N**, **Acesso**, **Memória** (só o dono) e **Comandos**. Em Skills há busca por nome e descrição, uma grade compacta e, para o dono, o filtro **Ligadas | Todas** (as desligadas aparecem esmaecidas) e o botão **Gerenciar skills**. A aba volta para Visão geral ao trocar de bot ou de servidor.

### Atualizar

O app se atualiza sozinho ao abrir. Só o app muda nesta versão: os servidores continuam como na 0.6.2.

### Instalar no Windows

Baixe `GhostLink-Setup-0.6.3.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.6.3.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.6.3" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.6.3.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.6.3.exe -sigfile GhostLink-Setup-0.6.3.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.6.3 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.6.3" \
   ```

## English

### What changed

- **Wider page:** every bot's page (Hermes, Ghost DJ and normal bots) now takes up to 1100 px, centered, and still fits a narrow window.
- **Tabs on the company Hermes:** right under the badge, **Overview**, **Skills N**, **Access**, **Memory** (owner only) and **Commands**. Skills has a search on name and description, a compact grid and, for the owner, the **On | All** filter (off skills look dimmed) and the **Manage skills** button. The tab goes back to Overview when the bot or the server changes.

### Updating

The app updates itself when it opens. Only the app changes in this version: servers stay as in 0.6.2.
