> **Beta.** Amigos e mensagens diretas na casinha, de computador para computador. *Friends and direct messages on the Home screen, computer to computer.* — [English below](#english)

## Português

### O que mudou

- **Amigos na casinha:** o **Início** agora é a página de **Amigos**, como no Discord, com as abas **Online**, **Todos**, **Pendentes** e **Bloqueados**. Os servidores ficam na coluna da esquerda, e o **Ativo agora** continua mostrando o servidor hospedado no seu PC.
- **Adicionar por código de amigo:** em **Adicionar amigo**, copie o seu código e mande para quem você quer adicionar, ou cole o código da pessoa. O pedido fica em **Pendentes** até ela **aceitar**. Dá para recusar, desfazer amizade, **bloquear** e gerar um código novo (o antigo para de valer; os amigos continuam).
- **Apelidos locais:** em **Mudar apelido**, dê a um amigo o nome que você quiser. Só você vê.
- **Mensagens diretas:** o botão **Mensagem** abre a conversa, que fica em **Mensagens diretas**, na lateral. Tem texto com a mesma formatação dos canais, **responder**, **editar**, **apagar** (some para os dois), contagem de **não lidas** e o aviso **"digitando…"**.
- **Sem servidor no meio:** as mensagens vão direto de um computador para o outro, criptografadas de ponta a ponta. Com os dois online, chegam na hora (✓ enviada, ✓✓ entregue). O que você escrever com o amigo offline fica guardado e **chega sozinho** quando vocês dois estiverem online.
- **Privacidade:** a rede de amigos é direta (P2P), então **seus amigos e quem tem o seu código de amigo veem o seu IP**. O app também usa a rede pública de amigos (a DHT do Hyperswarm) para achar seus amigos. Para sair dela, desligue **Ficar disponível para amigos**, em **Adicionar amigo**.
- **Em breve:** imagens e arquivos, grupos e chamadas nas mensagens diretas.

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Amigos e mensagens diretas funcionam entre apps na 0.3.0. Os servidores vão para a 0.3.0 sozinhos quando ninguém estiver em chamada, mas nada muda neles: amigos e mensagens diretas não passam por servidor.

Baixe `GhostLink-Setup-0.3.0.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

## English

### What changed

- **Friends on the Home screen:** **Home** is now the **Friends** page, as on Discord, with the **Online**, **All**, **Pending** and **Blocked** tabs. Servers live in the left column, and **Active now** still shows the server hosted on your PC.
- **Add by friend code:** in **Add friend**, copy your code and send it to the person you want to add, or paste theirs. The request waits in **Pending** until they **accept**. You can decline, remove a friend, **block**, and make a new code (the old one stops working; your friends stay).
- **Local nicknames:** with **Change nickname**, give a friend any name you like. Only you see it.
- **Direct messages:** the **Message** button opens the conversation, which stays under **Direct messages** in the sidebar. Text with the same formatting as channels, **reply**, **edit**, **delete** (gone for both of you), an **unread** count and **"typing…"**.
- **No server in between:** messages go straight from one computer to the other, end-to-end encrypted. With both of you online, they arrive at once (✓ sent, ✓✓ delivered). What you write while your friend is offline is kept and **arrives by itself** once you are both online.
- **Privacy:** the friends network is direct (P2P), so **your friends and anyone with your friend code can see your IP**. The app also uses the public friends network (the Hyperswarm DHT) to find your friends. To leave it, turn **Be available to friends** off, in **Add friend**.
- **Coming next:** images and files, group DMs and calls in direct messages.

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Friends and direct messages work between apps on 0.3.0. Servers move to 0.3.0 by themselves when no one is in a call, but nothing changes on them: friends and direct messages never go through a server.

### Install on Windows

Download `GhostLink-Setup-0.3.0.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.3.0.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
