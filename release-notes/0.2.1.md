> **Beta.** Correção: voltar a um servidor pelo mesmo convite. *Fix: coming back to a server through the same invite.* — [English below](#english)

## Português

### O que mudou

- **Voltar a um servidor pelo convite:** quem já entrou num servidor e abre o mesmo convite de novo (link, código colado ou endereço) agora entra direto, com o apelido de antes. O app não pede para aceitar o convite outra vez, e um convite que já esgotou os usos não atrapalha mais.
- Se o endereço do servidor mudou, os endereços do convite são usados primeiro e ficam salvos.

### Atualizar

Quem tem uma versão anterior instalada recebe esta sozinha (ao abrir o app, ou em até 6 horas) e só precisa clicar em **Reiniciar para atualizar**. Servidores de versões anteriores continuam funcionando com o app novo.

### Instalar no Windows

Baixe `GhostLink-Setup-0.2.1.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.2.1.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.2.1" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.2.1.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.2.1.exe -sigfile GhostLink-Setup-0.2.1.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.2.1 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.2.1" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   ```

## English

### What changed

- **Coming back to a server through its invite:** if you already joined a server and open the same invite again (link, pasted code or address), you now go straight in with your previous nickname. The app no longer asks you to accept the invite again, and an invite that ran out of uses no longer gets in the way.
- If the server's address changed, the invite's addresses are tried first and saved.

### Updating

If you have an earlier version installed, this one arrives by itself (when the app opens, or within 6 hours): just click **Restart to update**. Servers on earlier versions keep working with the new app.

### Install on Windows

Download `GhostLink-Setup-0.2.1.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.2.1.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
