> **Beta.** Bots, compatíveis com discord.js. *Bots, compatible with discord.js.* — [English below](#english)

## Português

### O que mudou

- **Bots:** na barra lateral do servidor, a seção **BOTS** fica acima de "Canais de texto". Quem gerencia o servidor clica em **+**, dá nome e foto ao bot e copia o **código de conexão** (ele aparece uma vez só). O bot entra com esse código, aparece com a etiqueta **BOT** e segue as permissões dos cargos. No menu do bot: **Gerar novo código** e **Excluir bot**.
- **Slash commands:** digite **/** na caixa de mensagem para ver os comandos dos bots do canal, preencha as opções e envie. A resposta mostra "Fulano usou /comando"; o bot também pode responder só para você ou mostrar "está pensando…" antes.
- **Migrar um bot do Discord:** o pacote `@ghostlink/discord-compat` (anexado a esta release) imita o discord.js na parte de mensagens e slash commands. Na maioria dos bots basta trocar `from 'discord.js'` por `from '@ghostlink/discord-compat'` e usar o código de conexão no lugar do token. Guia: https://gestao-in7eligente.github.io/ghostlink/bots

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Arquivos nas mensagens diretas funcionam entre apps na 0.4.0. Os servidores vão para a 0.4.0 sozinhos quando ninguém estiver em chamada; enviar arquivos nos canais funciona quando o servidor já estiver na 0.4.0.

### Instalar no Windows

Baixe `GhostLink-Setup-0.4.0.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.4.0.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.4.0" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.4.0.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.4.0.exe -sigfile GhostLink-Setup-0.4.0.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.4.0 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.4.0" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   ```

## English

### What changed

- **Bots:** in the server sidebar, the **BOTS** section sits above "Text channels". People who manage the server click **+**, give the bot a name and photo and copy its **connection code** (shown once). The bot joins with that code, shows a **BOT** tag and follows its roles' permissions. The bot's menu has **Generate new code** and **Delete bot**.
- **Slash commands:** type **/** in the message box to see the channel's bot commands, fill in the options and send. The reply shows "Someone used /command"; a bot can also answer only you, or show "is thinking…" first.
- **Moving a Discord bot over:** the `@ghostlink/discord-compat` package (attached to this release) mimics discord.js for messages and slash commands. For most bots, change `from 'discord.js'` to `from '@ghostlink/discord-compat'` and use the connection code instead of the token. Guide: https://gestao-in7eligente.github.io/ghostlink/en/bots

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Files in direct messages work between apps on 0.4.0. Servers move to 0.4.0 by themselves when no one is in a call; sending files in channels works once the server runs 0.4.0.

### Install on Windows

Download `GhostLink-Setup-0.4.0.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.4.0.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
