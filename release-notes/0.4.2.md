> **Beta.** Notificações próprias, cartão de perfil e as configurações do bot funcionando. *Own notification cards, the profile card and working bot settings.* — [English below](#english)

## Português

### O que mudou

- **Notificações do GhostLink:** os avisos aparecem num cartão próprio no canto da tela, em cima da barra de tarefas: foto, **Servidor ➜ #canal**, quem escreveu e a mensagem. Empilham até 3, somem em 5 s (com o mouse em cima, ficam), o clique abre a conversa e o **×** fecha. Valem para DMs, pedidos de amizade, menções e respostas e, se você quiser, **todas as mensagens** de um servidor: clique direito no servidor → **Notificações** (Todas as mensagens, Só @menções ou Nada). Desligue em **Configurações → Notificações**. Sem som.
- **Cartão de perfil:** clique no nome ou na foto de alguém, no chat ou na lista de membros: foto, status, desde quando está no servidor e os cargos. Quem gerencia cargos adiciona e tira ali mesmo; no **⋯** ficam **Mencionar** e **Copiar ID do usuário**. O clique direito continua com o menu de sempre.
- **Configurações do bot funcionando:** clique direito no bot → **Configurações**: nome, foto e descrição; uso dos comandos nos últimos 7 dias, as últimas interações e as mensagens das últimas 24 h; em quais canais o bot vê e fala, e os cargos dele; **Gerar novo código** e **Excluir bot**. Um bot feito com o pacote compatível pode escrever a própria descrição (`client.application.edit({ description })`).
- **Hermes Agent no GhostLink:** um plugin para o Hermes Agent (Nous Research) entrar num servidor GhostLink como bot, junto com o Discord. Fica em `integrations/hermes-agent` no repositório.

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). **Os servidores também mudam nesta versão** (configurações do bot) e se atualizam sozinhos quando ninguém está em chamada. Num servidor que ainda está na 0.4.1, as configurações do bot mostram "Atualize o servidor para editar".

### Instalar no Windows

Baixe `GhostLink-Setup-0.4.2.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.4.2.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.4.2" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.4.2.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:

   ```text
   -----END PUBLIC KEY-----
   ```
   ```bash

     -in GhostLink-Setup-0.4.2.exe -sigfile GhostLink-Setup-0.4.2.exe.ed25519
   ```
3. **Imagem Docker do servidor:**

## English

### What changed

- **GhostLink's own notifications:** alerts show up as GhostLink's own card in the corner of the screen, above the taskbar: picture, **Server ➜ #channel**, who wrote and the message. Up to 3 stack, each leaves after 5 s (they stay while the mouse is over them), a click opens the conversation and **×** closes it. They cover DMs, friend requests, mentions and replies and, if you want, **every message** of a server: right-click the server → **Notifications** (All messages, Only @mentions or Nothing). Turn them off in **Settings → Notifications**. No sound.
- **Profile card:** click someone's name or picture, in the chat or the member list: picture, status, when they joined the server and their roles. Whoever manages roles adds and removes them right there; **⋯** holds **Mention** and **Copy user ID**. Right-click keeps the usual menu.
- **Working bot settings:** right-click a bot → **Settings**: name, picture and description; command use over the last 7 days, the latest interactions and the messages of the last 24 h; which channels the bot sees and speaks in, and its roles; **Generate new code** and **Delete bot**. A bot built with the compatible package can write its own description (`client.application.edit({ description })`).
- **Hermes Agent on GhostLink:** a plugin that lets Hermes Agent (Nous Research) join a GhostLink server as a bot, alongside Discord. It lives in `integrations/hermes-agent` in the repository.

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). **Servers change in this version too** (bot settings) and update themselves when nobody is in a call. On a server still on 0.4.1, the bot settings show "Update the server to edit".

### Install on Windows

Download `GhostLink-Setup-0.4.2.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.4.2.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
