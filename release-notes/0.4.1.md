> **Beta.** Página do bot e as configurações do bot (prévia). *The bot page and bot settings (preview).* — [English below](#english)

## Português

### O que mudou

- **Página do bot:** clique num bot na seção **BOTS** para abrir a página dele no centro (como um canal): foto, estado e a lista de **comandos** com as opções de cada um.
- **Configurações do bot (prévia):** no clique direito do bot, **Configurações** abre a tela do bot com as abas Visão geral, Comandos, Atividade, Permissões, Código de conexão e Excluir bot. Por enquanto é uma **prévia** com dados de exemplo; as ações chegam numa próxima versão. **Gerar novo código** e **Excluir bot** no clique direito continuam funcionando.

### Atualizar

O app se atualiza sozinho ao abrir (ou em **Configurações → Atualizações → Procurar atualizações**). Nada muda nos servidores nesta versão.

### Instalar no Windows

Baixe `GhostLink-Setup-0.4.1.exe` abaixo. O instalador ainda não tem assinatura de código paga, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**. O app instala só para o seu usuário, sem pedir administrador.

### Servidor numa VPS

`ghostlink-server-0.4.1.tgz` é o servidor para Linux (x64 e arm64, Node 24). O `install.sh` desta release instala, confere as assinaturas e cria o serviço. Guia: https://gestao-in7eligente.github.io/ghostlink/hospedar-em-vps

### Verificar os downloads

1. **Checksums com Sigstore (cosign):**
   ```bash
   cosign verify-blob checksums-sha256.txt \
     --bundle checksums-sha256.txt.sigstore.json \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.4.1" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   sha256sum --ignore-missing -c checksums-sha256.txt
   ```
   No Windows (PowerShell): `Get-FileHash .\GhostLink-Setup-0.4.1.exe -Algorithm SHA256` e compare com a linha do arquivo em `checksums-sha256.txt`.
2. **Assinatura Ed25519 da release** (a mesma que o app confere antes de se atualizar). Salve a chave pública como `ghostlink-release.pem`:
   ```text
   -----BEGIN PUBLIC KEY-----
   MCowBQYDK2VwAyEAHhib591tl4P4Nf9us1fB5FCXXbGOZDBHwvWIu+2FWnc=
   -----END PUBLIC KEY-----
   ```
   ```bash
   openssl pkeyutl -verify -pubin -inkey ghostlink-release.pem -rawin \
     -in GhostLink-Setup-0.4.1.exe -sigfile GhostLink-Setup-0.4.1.exe.ed25519
   ```
3. **Imagem Docker do servidor:**
   ```bash
   cosign verify ghcr.io/gestao-in7eligente/ghostlink-server:0.4.1 \
     --certificate-identity "https://github.com/gestao-in7eligente/ghostlink/.github/workflows/release.yml@refs/tags/v0.4.1" \
     --certificate-oidc-issuer https://token.actions.githubusercontent.com
   ```

## English

### What changed

- **Bot page:** click a bot in the **BOTS** section to open its page in the center (like a channel): photo, status and its **commands** with each one's options.
- **Bot settings (preview):** right-click a bot, **Settings** opens the bot's screen with Overview, Commands, Activity, Permissions, Connection code and Delete bot tabs. For now it is a **preview** with sample data; the actions come in a later version. **Generate new code** and **Delete bot** on right-click still work.

### Updating

The app updates itself when it opens (or in **Settings → Updates → Check for updates**). Nothing changes on servers in this version.

### Install on Windows

Download `GhostLink-Setup-0.4.1.exe` below. The installer has no paid code-signing certificate yet, so Windows SmartScreen warns the first time: click **More info → Run anyway**. The app installs for your user only, without asking for administrator rights.

### Server on a VPS

`ghostlink-server-0.4.1.tgz` is the Linux server (x64 and arm64, Node 24). This release's `install.sh` installs it, checks the signatures and creates the service. Guide: https://gestao-in7eligente.github.io/ghostlink/en/host-on-vps
