> **Beta.** Criar um servidor na nuvem (Railway) volta a funcionar. *Creating a cloud (Railway) server works again.* — [English below](#english)

## Português

### O que mudou

- **Criar servidor no Railway corrigido:** o servidor novo agora sobe direto na imagem certa da sua versão, então o passo "Publicando o servidor" não falha mais.
- Correções e melhorias internas de estabilidade.

### Atualizar

O app se atualiza sozinho ao abrir. O servidor também muda nesta versão e se atualiza quando ninguém está em chamada.

### Instalar no Windows

Baixe `GhostLink-Setup-0.8.6.exe` abaixo. O Windows SmartScreen avisa na primeira vez: **Mais informações → Executar assim mesmo**. Instala só para o seu usuário, sem administrador.

## English

### What changed

- **Railway server creation fixed:** a new server now boots straight on the right image for its version, so the "Publishing the server" step no longer fails.
- Internal stability fixes and improvements.

### Updating

The app updates itself when it opens. The server changes in this version too and updates itself when nobody is in a call.

### Install on Windows

Download `GhostLink-Setup-0.8.6.exe` below. Windows SmartScreen warns the first time: **More info → Run anyway**. Installs for your user only, no administrator.
