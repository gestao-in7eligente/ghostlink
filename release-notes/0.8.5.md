> **Beta.** Criar servidor no Railway ficou mais seguro: testar o token antes de salvar e trocá-lo com clareza. *Creating a Railway server is safer now: test the token before saving and change it clearly.* — [English below](#english)

## Português

### O que mudou

- Ao criar um servidor **na nuvem (Railway)**, agora há um botão **Testar** ao lado do salvar: ele confere o token com o Railway **sem gravar**, então um token errado é pego antes de conectar. E, quando já conectado, o botão **Trocar token** deixa claro como corrigir.
- Correções e melhorias internas de estabilidade.

### Atualizar

O app se atualiza sozinho ao abrir. O servidor também muda nesta versão e se atualiza quando ninguém está em chamada.

### Instalar no Windows

Baixe `GhostLink-Setup-0.8.5.exe` abaixo. O Windows SmartScreen avisa na primeira vez: **Mais informações → Executar assim mesmo**. Instala só para o seu usuário, sem administrador.

## English

### What changed

- When creating a **cloud (Railway)** server, there is now a **Test** button next to save: it checks the token with Railway **without storing it**, so a wrong token is caught before connecting. Once connected, the **Change token** button makes fixing it obvious.
- Internal stability fixes and improvements.

### Updating

The app updates itself when it opens. The server changes in this version too and updates itself when nobody is in a call.

### Install on Windows

Download `GhostLink-Setup-0.8.5.exe` below. Windows SmartScreen warns the first time: **More info → Run anyway**. Installs for your user only, no administrator.
